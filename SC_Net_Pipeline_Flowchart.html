📥 Phase 1 — Input Data: Coronary CT Angiography (CCTA)
🫀 CPR Volume (.nii / .nii.gz)
  • Curved Planar Reformatted (CPR) vessel cross-section extracted from CCTA scan
  • Target shape: 256 × 64 × 64 (Depth × Height × Width)
  • Raw Hounsfield Unit (HU) values stored in NIfTI format
  • Loaded via nibabel; axes transposed to (D, H, W) if originally stored as (H, W, D)
  • Depth axis = proximal → distal along vessel centerline
🏷️ Stenosis Labels NEW FORMAT
  • File: *_stenosis.txt — 256 integer values (one per depth slice)
  • 0 = Background  |  1–2 = Non-significant  |  3–4 = Significant stenosis
🏷️ Plaque Labels NEW FORMAT
  • File: *_plaque.txt — 256 integer values
  • 0 = Background  |  1 = Calcified  |  2 = Non-calcified  |  3 = Mixed
⚙️ merge_new_labels(stenosis, plaque) NEW
  • Non-significant (1–2) + Plaque → combined label: 1, 2, 3
  • Significant (3–4) + Plaque → combined label: 4, 5, 6
  • Background (0) stays 0
Non-sig × {Calc, NonCalc, Mixed} → {1, 2, 3}
Sig × {Calc, NonCalc, Mixed} → {4, 5, 6}
Old format fallback: single combined .txt file read directly
📊 Dataset Statistics
  • Training pool: 2,961 files (APNHC patients)
  • Held-out test set: 665 files (AP-NUH patients — completely separate hospital)
  • Internal split of train pool: 70/15/15 (train/val/test)
  • Per-artery volumes: LAD, LCX, RCA and branches
  • 6 combined label classes for fine-tuning; 3 for pre-training
🔀 Phase 2 — Patient-Level Data Splitting (splitting.py)
📂 _build_file_pairs(volumes_root, labels_root)
  • Scans volumes/ directory and matches each volume to its labels by stem name
  • Prefers new format: .nii.gz + separate _stenosis.txt / _plaque.txt
  • Falls back to old format: .nii + combined label .txt
  • Returns list of (vol_path, sten_path, plaq_path, comb_path) tuples
  • Deduplicates stems — avoids double-counting .nii and .nii.gz
👥 patient_level_split() Anti-Leakage
  • Extracts PatientID from filename: P001_LAD.nii → P001
  • Groups all arteries from the same patient together
  • Shuffles patients (not files) with seed=42 for reproducibility
  • Split: 70% Train / 15% Validation / 15% Test at patient level
  • Guarantees: no patient appears in more than one split — prevents data leakage
⚠️ Critical Design Choices
  • File indices (not raw filenames) passed to cubic_sequence_data to maintain alignment with file_pairs
  • Early stopping monitored on validation set, not test set
  • BUG FIX  Trainer previously used test split for validation monitoring (leaked test data into early-stopping decisions) — now correctly uses val indices
  • Held-out test set (dataset/test/) never seen during training or calibration
⚙️ Phase 3 — Preprocessing, Augmentation & DataLoader (augmentation.py + functions.py)
Data Loading & Preprocessing
📦 cubic_sequence_data.__getitem__(index)
  • Maps index → actual file pair via patient-split file_indices
  • Loads volume using nibabel.load() → get_fdata()
  • Transposes if stored as (H,W,D): checks shape[2] > shape[0]
  • Resizes to [256, 64, 64] via scipy.ndimage.zoom(order=3) (cubic spline)
  • Loads labels: merges stenosis + plaque if separate files
  • Resizes labels to depth=256 via zoom(order=0) (nearest-neighbour to preserve integer classes)
  • Label remapping (pre-training): ((lbl−1) % 3) + 1 → maps 6-class to 3-class (plaque composition)
🪟 HU Windowing — normalize_ct_data()
  • Standard (single channel):
  •   Center=300 HU, Width=900 HU → range [−150, 750 HU] → normalized to [0, 1]
  •   Output: [D, H, W] float tensor
  • Multi-window (3 channels): NEW
  •   Ch 0 — Soft tissue:   HU [−150,  750] → [0,1]
  •   Ch 1 — Calcium/bone:  HU [−450, 1050] → [0,1]
  •   Ch 2 — Vascular:      HU [−250,  450] → [0,1]
  •   Output: [3, D, H, W] float tensor
📍 detection_targets(labels)
  • Scans depth axis for contiguous lesion segments (tracks label transitions)
  • Each segment → 1D bounding box: [center, width] normalized to [0, 1] along depth
  • Label = segment class − 1 (zero-indexed for CE loss)
  • Output: {"labels": Tensor[N], "boxes": Tensor[N, 2]}
  • Healthy/background volume → empty tensors shape (0, 2)
🗂️ collate_fn() + DataLoader
  • Stacks images into batch: [B, D, H, W] or [B, 3, D, H, W]
  • Keeps targets as list of dicts (variable number of boxes per sample)
  • batch_size=2, shuffle=True (train), num_workers=4
  • Balanced sampling: inverse-frequency sample weights per lesion class to counter class imbalance
Augmentation Strategies
🔄 Online Augmentation — online_augment() NEW
  • Applied during training only; random per sample
  • Axial rotation: ±15° applied identically to all slices (p=0.5) — vessel stays centered
  • Depth flip: reverse along D-axis, labels flipped in sync (p=0.5)
  • Intensity shift: global HU offset ±50 (p=0.5) — preserves relative tissue contrast
  • Designed to preserve lesion spatial structure; heavy distortions excluded
🔬 Offline Augmentation — clinically_credible_augmentation (CDA) CDA NEW
  • Purpose: Synthesize new training samples by splicing lesion segments from one scan into background of another
  • Step 1 — Resize: both foreground (lesion) and background volumes resized to [256,64,64] via cubic zoom
  • Step 2 — Splice: background slices (label=0) filled from background scan; foreground slices (label>0) filled from foreground scan
  • Step 3 — Intensity Matching: normalize foreground intensity to match background distribution (z-score normalization)
  • Step 4 — Soft Blending: cosine blending at foreground/background boundaries (blend_margin=3 slices) to avoid sharp seams
  • Saved as new NIfTI files for use in training; does not run per-batch
🧠 Phase 4 — SC-Net Architecture: spatio_temporal_semantic_learning (architecture.py)
Model Input Tensor: [B, D, H, W] = [B, 256, 64, 64]  —  or  [B, 3, D, H, W] for multi-window mode
Both branches receive the same input simultaneously and run in parallel
🕐 BRANCH 1: Temporal Semantic Learning (sampling_point_framework — temporal_semantic_learning)
① _3d_cubes_selection()  — functions.py
Extracts 32 cubic crops of size 25³ voxels along the vessel depth axis
Centers placed at: step/2 + step×i, with step=8 (evenly spaced proximal→distal)
Handles boundary crops with zero-padding
Output: [B, 32, 25, 25, 25]
↓
② Conv3d — 4-Level 3D CNN
Processes all 32 cubes together as a temporal sequence
4 levels: 1→16→32→64→128 channels
Each level: Conv3d(3×3×3) + BatchNorm3d + ReLU + MaxPool3d(2×2×2)
Output: [B, 32, 128, d', h', w']
CRITICAL FIX  Previously cubes were processed 1-at-a-time (l=1), disabling the temporal transformer entirely. Now all 32 cubes form a true temporal sequence.
↓
③ temporal_flattening_projection
Conv3d(1×1×1) → Flatten spatial dims → Linear(flat_dim → 512)
Projects each of the 32 cube feature maps to 512-dim embedding
Output: [B, 32, 512]
↓
④ Learnable Positional Encoding  NEW
Parameter shape: [1, 32, 512] — initialized with truncated normal (std=0.02)
Encodes proximal→distal vessel ordering for self-attention
Added element-wise: x = x + pos_embedding[:, :32, :]
↓
⑤ temporal_correlation_analysis — Transformer Encoder
4-layer TransformerEncoderLayer (nhead=8, dropout=0.1, activation=ReLU, batch_first=True)
Full self-attention across all 32 cube positions simultaneously
Captures long-range dependencies along vessel (e.g., distal lesion affecting proximal context)
Output: [B, 32, 512]
↓
⑥ sampling_point_classify — MLP Head
Linear(512 → 128) → GELU → Linear(128 → num_classes+1)
Softmax applied at test time; raw logits used during training for stability
Output: [B, 32, num_classes+1]  —  per-cube class probabilities along vessel
SC Output: xs = {pred_logits: [B, 32, C+1]}
32 sampling-point predictions along vessel depth
🗺️ BRANCH 2: Spatial Semantic Learning (object_detection_framework — spatial_semantic_learning)
① feature_extraction_3d — Hybrid 3D + 2D CNN (4 Levels)
Input: [B, 1, 256, 64, 64] (unsqueezed if single-channel)
Feature maps progression: 1 → 16 → 32 → 64 → 128 channels across 4 levels
_3d_extraction_block (at each level i):
2–3 stacked Conv3d(3×3×3) + BatchNorm3d + ReLU + MaxPool3d
Captures full volumetric vessel context
_2d_extraction_block (at each level i): MULTI-VIEW
Extracts 4 complementary 2D planar views from the 3D volume:
  • View 1: Axial slice at mid-height (H/2)
  • View 2: Sagittal slice at mid-width (W/2)
  • View 3: Diagonal plane (D × H × W, ↗ direction)
  • View 4: Anti-diagonal plane (↘ direction)
2D Conv layers applied to each view → features projected back to 3D using learned weights [1, 4, 1, 1, 1, 1]
Weighted Fusion (levels 1–3):
x_3d = α × 3D_features + (1 − α) × 2D_features
α = 0.75 (_3d_weight, learnable scalar parameter)
Level 0: 3D and 2D applied independently (no fusion)
↓
② spatial_flattening_projection
Conv3d(1×1×1) to reduce channels (128→16) + Flatten + Linear
Converts 3D feature map to sequence of spatial tokens
Output: [B, 16, 512] (16 spatial feature positions as memory for transformer)
↓
③ nn.Transformer — DETR-Style Encoder-Decoder
Encoder: 4 layers over spatial feature sequence (as memory keys/values)
Decoder: 4 layers with Q=16 learnable query embeddings (nn.Embedding(16, 512))
Each query independently attends to the entire spatial memory
Each query slot = one potential lesion object proposal
Output: [B, 16, 512] (16 decoded object representations)
↓
④ bounding_box_prediction — Dual MLP Heads
class_prediction:  MLP(512→256→num_classes+1) → class logits (Softmax at test time)
boxes_prediction: MLP(512→256→2) → Sigmoid → [center, width]
Boxes are 1D intervals along vessel depth axis, normalized to [0, 1]
Output: xc [B, 16, C+1]  +  xb [B, 16, 2]
OD Output: {pred_logits: xc [B,16,C+1], pred_boxes: xb [B,16,2]}
16 lesion proposals: each with a class score + 1D bounding box
Combined Forward Output (ret_map=True):
od_output = {"pred_logits": xc, "pred_boxes": xb}     sc_output = {"pred_logits": xs}
📉 Phase 5 — Loss Functions: spatio_temporal_contrast_loss (optimization.py)
⚙️ L_od — Object Detection Loss Spatial Branch
  • Step 1 — Hungarian Matching (functions.py: HungarianMatcher):
  •   Boxes expanded: [cx, w] → [cx, 0.5, w, 1.0] for GIoU computation
  •   Cost matrix: cost_class=1, cost_bbox=1, cost_giou=1
  •   Solved via scipy.optimize.linear_sum_assignment
  • Step 2 — CE Loss on class predictions:
  •   Empty/no-object class weighted by eos_coef=0.15
  • Step 3 — Box Regression Loss:
L_od = CE + 5 × L1 + 2 × GIoU
λ_L1=5, λ_GIoU=2 (MICCAI paper Eq. 5)
⚙️ L_sc — Sampling Point Classification Temporal Branch
  • Weighted Cross-Entropy: background=0.5×, lesion classes=1.5×
  • boost_nonsig: Non-significant class weight doubled (2× lesion weight)
  • Focal Loss (γ=2.0): NEW
  •   Downweights easy/confident predictions, focuses on hard examples
  • Ordinal EMD Loss (weight=0.5): NEW
EMD = ‖CDF(pred) − CDF(target)‖²
  • Penalizes Healthy↔Significant errors more than adjacent class errors (ordinal distance)
  • Label smoothing (ε=0.1): prevents overconfidence on one-hot targets
⚙️ L_dc — Dual-Task Contrastive Loss Cross-Branch
  • Forces mutual consistency between the two branches
  • SC→OD: SC per-point predictions converted to pseudo-boxes for OD supervision
  • OD→SC: OD proposals converted to per-slice pseudo-labels for SC supervision
  • Confidence gating: only predictions with p > 0.3 used as pseudo-labels
  • Warm-up schedule: L_dc held at 0 for first 20 epochs, linearly ramped over next 30 epochs
L_dc = L_od(C(ŷ_sc), ŷ_od) + L_sc(C⁻¹(ŷ_od), ŷ_sc)
Soft DC enabled: smooth pseudo-label interpolation instead of hard one-hot
📐 Total Combined Loss
L_total = L_od + L_sc + δ × L_dc
δ = 1.0 (dual-task contrastive weight)  ·  Gradients from all three terms flow back through both branches simultaneously
🏋️ Phase 6 — Two-Stage Training Pipeline (train.py + framework.py + scheduler_utils.py)
Two-Stage Training Strategy
Stage 1: PRE-TRAINING (3-class)
  • Task: Plaque composition only — Calcified / Non-calcified / Mixed
  • Labels remapped: ((lbl−1) % 3) + 1 to collapse 6→3 classes
  • Trains vessel feature representation + basic plaque discrimination from scratch
  • LR: 3×10⁻⁵  |  ~50–60 epochs
  • Fresh random initialization of all weights
  • num_classes=3 → heads size differs from fine-tuning
  • Best backbone: v6, epoch 8 (val loss 3.22) — selected as finest pre-trained base
→
Stage 2: FINE-TUNING (6-class)
  • Task: Full stenosis severity × plaque composition (6 classes)
  • Non-sig × {Calc, NonCalc, Mixed} = classes 1–3
  • Significant × {Calc, NonCalc, Mixed} = classes 4–6
  • Loads pre-trained backbone (shape-compatible layers only via filtered state_dict)
  • Classification heads (3-class → 6-class) re-initialized from scratch by design
  • LR: 5×10⁻⁶ (3–5× lower than pre-training)  |  ~40–50 epochs
  • Best model: v7-ft epoch 49 — final_model.pth
Optimizer, LR Schedule & Training Infrastructure
⚡ AdamW Optimizer
  • weight_decay=1×10⁻⁴  |  grad_clip=0.1
  • Layer-wise LR multipliers: NEW
  •   Backbone (3D/2D conv): 0.1× base LR
  •   Transformer layers: 0.5× base LR
  •   Classification heads: 1.0× base LR (full LR)
  • BUG FIX Temporal transformer was getting backbone LR (0.1×) due to wrong parameter name match — now correctly gets 0.5×
📈 Learning Rate Schedule
  • Option A — LinearWarmupCosineDecay:
  •   Linear warmup for 10 epochs → cosine annealing to min_lr
  • Option B — CosineAnnealingWarmRestarts: NEW
  •   T₀=60 epochs, T_mult=2 (each cycle doubles in length)
  •   Restarts re-raise LR to escape local minima
  •   Effective cycles: 60 → 120 → 240 epochs
  • Both include linear warmup phase
🔧 Weight Averaging Techniques
  • EMA — Exponential Moving Average:
  •   decay=0.999  |  Shadow weights updated each step
  •   Smoother loss landscape; applied at eval/checkpoint save time
  • SWA — Stochastic Weight Averaging: NEW
  •   Averages model weights starting from epoch 120
  •   Uses SWALR scheduler; BN statistics updated at end
  •   Finds flatter minima → better generalization
  •   Saves swa_model.pth alongside final checkpoint
🏗️ Training Infrastructure
  • AMP: Mixed-precision (fp16/fp32) with GradScaler
  • DDP: DistributedDataParallel — 2× NVIDIA RTX 3090 (24 GB each)
  •   Launched with torchrun --nproc_per_node=2
  •   Val loss all-reduced across ranks before early-stopping check
  • BUG FIX NCCL DDP timeout: ranks diverged on patience counter due to local val loss — fixed with dist.all_reduce
  • Gradient accumulation: accumulate_steps=4 (effective batch=8)
  • Early stopping: patience=60, min_delta=0.001
  • TensorBoard logging every 10 epochs
📊 Phase 7 — Evaluation Pipeline (eval.py)
🔄 Prediction Aggregation
  • od_predictions_to_artery_level():
  • Aggregates 16 OD query proposals per volume → one artery-level prediction
  • Takes the highest-confidence non-background class across all 16 proposals
  • Maps 6-class → Stenosis (3-class) + Plaque (3-class):
  •   Classes 1–3 = Non-significant  |  Classes 4–6 = Significant
  •   Class modulo-3 → Calcified / Non-calcified / Mixed
  • targets_to_artery_level(): identical mapping for ground truth
🔁 Test-Time Augmentation (TTA) NEW
  • tta_k=5 stochastic augmented versions per test sample
  • Apply online_augment() independently K times
  • Run model forward pass for each augmented version
  • Average raw logits across all K passes before argmax
  • Reduces variance from augmentation randomness at test time
🗳️ Ensemble Inference NEW
  • Load N checkpoint files (e.g., epoch snapshots or separately trained runs)
  • Run full inference with each model independently on the same test set
  • Average softmax probabilities across all N models
  • Reduces model-specific overfitting; compatible with TTA

  • Per-class: Precision, Recall, F1, Support, Specificity
  • AUC-ROC (one-vs-rest, macro-averaged)
  • Confusion matrix (absolute counts)

⚖️ Phase 8 — Per-Class Threshold Calibration (calibrate.py) NEW
① Collect Validation Probabilities
  • Run full inference on the validation split (never the test set)
  • Collect 3-class stenosis softmax probabilities per artery
  • Store: probs_array [N_arteries, 3] and ground-truth labels
  • Supports both single-model and ensemble inputs
② Threshold Decision Rule
pred = argmax(pᵢ / tᵢ)   for i ∈ {Healthy, NonSig, Sig}
  • Default argmax = uniform thresholds t=[1,1,1]
  • Lower t_sig → model more willing to predict Significant
  • Higher t_healthy → model less willing to predict Healthy
  • Lower t_nonsig → recovers Non-significant class recall
③ Grid Search Strategies
  • Standard 2D search: t_nonsig=1.0 fixed; search t_healthy × t_sig (50×50 grid)
  • Constrained 3D search: KEY RESULT
  •   Search all three thresholds simultaneously (50³ grid)
  •   Constraint: Non-sig recall ≥ 10%
  •   Objective: maximize macro-F1
  • Result: Non-sig recall 0% → 58%  |  F1: 0.466 → 0.585 (+25.5%)
  • Key insight: 2D search misses Non-sig sweet spot (t_nonsig=0.35)
④ Save & Apply Thresholds
  • Saves to calibration_thresholds.json with keys:
  •   stenosis_thresholds: standard 2D result
  •   constrained_stenosis_thresholds: 3D constrained result
  •   plaque_thresholds: separate plaque calibration
  • Applied at test time via: eval.py --thresholds FILE --use_constrained
  • Best: calibration_thresholds_v7_constrained.json
🎲 Phase 9 — Uncertainty Estimation: Monte Carlo Dropout (uncertainty.py) NEW
① enable_dropout(model)
  • Sets all Dropout layers to train mode while keeping all other layers in eval mode
  • Enables stochastic forward passes at test time (non-deterministic Dropout)
  • No gradient computation (wrapped in @torch.no_grad())
② N=10 MC Forward Passes
  • Same input volume processed N=10 times with different Dropout masks
  • Each pass: extract OD logits [1, 16, C+1] → Softmax → max probability across 16 proposals
  • Stack all passes: mc_probs [10, C+1]
③ Uncertainty Quantification
  • Mean probabilities: mean_probs = mc_probs.mean(axis=0)
  • Variance: variance = mc_probs.var(axis=0) — per-class spread
  • Predictive entropy:
H = −Σ p̄ · log(p̄ + ε)
  • High entropy → high uncertainty → flag case for radiologist review
  • Results saved to uncertainty_results.json keyed by artery ID
🎯 Phase 10 — Final Clinical Output
🫀 Stenosis Classification (per artery)
  • 🟢 Healthy — No significant stenosis detected
  • 🟡 Non-significant — <50% lumen narrowing
  • 🔴 Significant — ≥50% lumen narrowing (clinically actionable)
Calibrated probability per class  |  Threshold-adjusted prediction
🧫 Plaque Composition (per artery)
  • ⚪ Calcified — Dense, stable plaque
  • 🟤 Non-calcified — Soft plaque (higher vulnerability / rupture risk)
  • 🟠 Mixed — Combination of calcified + non-calcified components
Jointly predicted with stenosis from the same dual-branch model
📍 Lesion Localization
  • OD branch outputs 1D bounding boxes [center, width] normalized to [0, 1] along vessel depth axis
  • Maps to specific segment position along the coronary artery CPR
  • Up to 16 lesion proposals per volume
  • Temporal branch provides independent per-slice class labels at 32 positions
🎲 Confidence & Uncertainty
  • Calibrated class probabilities (scaled by thresholds)
  • MC Dropout predictive entropy per case
  • High-entropy cases automatically flagged for expert radiologist review
  • Variance across MC passes available per class
